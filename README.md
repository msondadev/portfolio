# Portfolio Personal - [Martin Sonda]

Este es mi portfolio, diseñado para mostrar mis proyectos y servicios como desarrollador. Mi objetivo principal fue crear una interfaz limpia, rápida y funcional para conectar con clientes y colegas, priorizando siempre una excelente experiencia de usuario (UX).

---

## 🔗 Ver sitio en vivo
👉 **[https://msondadev.github.io/portfolio/]**

---

## 🛠️ Tecnologías
* **Frontend:** React + Vite.
* **Estilos:** Bootstrap & Styled Components.
* **Formulario:** EmailJS (Envío de correos directo).
* **Iconos:** React Icons.

---

## ✨ Características
* **Modo Oscuro/Claro:** Elige la visualización que prefieras.
* **Diseño Adaptable:** Se ve bien en computadoras, tablets y celulares.
* **Contacto Directo:** Formulario funcional que llega directamente a mi email.

---

## 🚀 Cómo ejecutarlo localmente
1. Clonar: `git clone https://github.com/msondadev/portfolio.git`
2. Instalar: `npm install`
3. Crear un archivo `.env` con tus credenciales de EmailJS.
4. Correr: `npm run dev`
